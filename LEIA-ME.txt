CONVITE Y2K — COMO RODAR NO VS CODE

1. Instale o Node.js (versão LTS) se ainda não estiver instalado: https://nodejs.org/
2. Abra esta pasta no VS Code.
3. No terminal do VS Code, execute: npm install
4. Copie .env.example para um arquivo chamado .env.
   No PowerShell, pode usar: Copy-Item .env.example .env
5. Abra o arquivo .env e troque ADMIN_PASSWORD por uma senha forte e SESSION_SECRET por uma frase/chave longa e aleatória.
6. Inicie o projeto: npm start
7. Abra no navegador: http://localhost:3000
8. Área administrativa: http://localhost:3000/admin

As confirmações são guardadas localmente em data/confirmacoes.json. A área administrativa consulta os dados por rotas protegidas no servidor. Não publique o arquivo .env nem compartilhe a senha administrativa.

PERSONALIZAÇÃO
No arquivo public/index.html, procure por [SEU NOME], [DIA / MÊS], [HORÁRIO] e [ENDEREÇO DA FESTA] e substitua pelos dados reais.

IMPORTANTE SOBRE PUBLICAR NA INTERNET
Este projeto é uma primeira versão local. Antes de publicar, será necessário configurar HTTPS, armazenamento persistente adequado ao serviço de hospedagem, proteção contra tentativas repetidas de login e um segredo de sessão seguro. O arquivo JSON local pode não persistir em algumas hospedagens.
